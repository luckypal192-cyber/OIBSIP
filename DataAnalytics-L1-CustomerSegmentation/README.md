# Customer Segmentation Analysis

## Oasis Infobyte – Data Analytics Internship

### Task 2 – Customer Segmentation Analysis

## Objective

The objective of this project is to segment customers based on their purchasing behavior using RFM (Recency, Frequency, and Monetary) analysis and K-Means clustering.

The analysis helps identify different customer groups and provides insights that can support targeted marketing and customer retention strategies.

## Dataset

The project uses the **Online Retail** dataset containing transaction-level data from an e-commerce business.

### Important Columns

- InvoiceNo – Invoice number
- StockCode – Product code
- Description – Product description
- Quantity – Number of products purchased
- InvoiceDate – Date and time of transaction
- UnitPrice – Price per unit
- CustomerID – Unique customer identifier
- Country – Customer's country

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Methodology

### 1. Data Loading and Inspection

The Online Retail dataset was loaded using Pandas and inspected to understand its structure, columns, data types, and missing values.

### 2. Data Cleaning

The dataset was cleaned by:

- Removing cancelled transactions
- Removing records with missing CustomerID
- Removing transactions with invalid quantities
- Removing transactions with invalid unit prices
- Converting CustomerID into integer format

After cleaning, the dataset contained **397,884 rows and 8 columns**.

### 3. RFM Analysis

Three behavioral features were selected for customer segmentation:

- **Recency** – Number of days since the customer's most recent purchase
- **Frequency** – Number of unique invoices/orders made by the customer
- **Monetary** – Total purchase value generated by the customer

### 4. Feature Standardization

The RFM features were standardized using `StandardScaler` before applying the clustering algorithm.

### 5. Elbow Method

The Elbow Method was used to determine the appropriate number of clusters.

Based on the Elbow Method, **5 clusters** were selected for the K-Means model.

### 6. K-Means Clustering

K-Means clustering was applied with:

- Number of clusters: **5**
- Random state: **42**
- Number of initializations: **10**

## Cluster Analysis

| Cluster | Customer Type | Customers |
|---|---|---:|
| 0 | Regular / Low-Value Customers | 3,049 |
| 1 | Inactive / At-Risk Customers | 1,062 |
| 2 | Loyal High-Value Customers | 213 |
| 3 | Very High-Value / VIP Customers | 8 |
| 4 | Exceptional High-Spending Customers | 6 |

### Cluster 0 – Regular / Low-Value Customers

These customers purchase relatively regularly but have moderate spending.

**Marketing Strategy:** Personalized product recommendations, loyalty points, and cross-selling offers can help increase purchase frequency and spending.

### Cluster 1 – Inactive / At-Risk Customers

These customers have high recency and relatively low purchase frequency and monetary value.

**Marketing Strategy:** Re-engagement campaigns, reminder emails, limited-time offers, and special promotions can be used to encourage repeat purchases.

### Cluster 2 – Loyal High-Value Customers

These customers purchase recently, have high purchase frequency, and generate significant revenue.

**Marketing Strategy:** Loyalty benefits, early access to new products, personalized offers, and premium customer service can help retain these customers.

### Cluster 3 – Very High-Value / VIP Customers

This is a very small but highly active and valuable customer segment.

**Marketing Strategy:** VIP membership, exclusive products, priority support, and personalized relationship management can be provided.

### Cluster 4 – Exceptional High-Spending Customers

This segment contains very few customers but has exceptionally high monetary value.

**Marketing Strategy:** Customer retention, premium services, personalized communication, and dedicated account management should be prioritized.

## Key Insights

- Cluster 0 represents the largest customer segment.
- Cluster 1 represents customers who may require re-engagement.
- Clusters 2, 3, and 4 represent valuable customer segments.
- Clusters 3 and 4 are very small segments but have exceptionally high spending and purchase frequency.
- RFM-based segmentation can help businesses create targeted marketing strategies instead of treating all customers equally.

## Conclusion

Customer Segmentation Analysis was performed using RFM analysis and K-Means clustering.

Five customer segments were identified based on recency, purchase frequency, and monetary contribution. The analysis revealed regular customers, inactive or at-risk customers, loyal high-value customers, and small but exceptionally valuable customer segments.

These insights can help businesses develop targeted marketing strategies, improve customer retention, and focus resources on high-value customer groups.

Overall, RFM-based K-Means clustering provides a data-driven approach for understanding customer behavior and supporting personalized marketing decisions.
